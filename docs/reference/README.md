# Inspiration images

Four reference photos that define the look and navigation of the app. Agents should treat them as visual direction, not as assets to ship.

| File | What it shows | Informs |
|---|---|---|
| `01-lid-and-tabs.png` | Wooden recipe box, front-on. A recipe card stands in the open lid; three tabs (Entrées, Soups/Salads, Sauces) sit in front. Engraved "recipes" on the front. | R1: Box View layout (card in the lid on top, tabs below). v1 uses this front-on view. |
| `02-alphabetical-dividers.png` | Vintage wooden file box with alphabetical dividers A to Z, staggered in rows so many tabs fit. | R4: alphabetical sort system and staggered tab rows on narrow screens. |
| `03-wild-west-box.png` | A yellow box packed with mixed clippings, recipe cards and printed pages in different sizes and colors, with category tabs (Salads, Pies and Pastries, Casseroles, Vegetables, Poultry). | R9: the Wild West look, where each card looks like its source. |
| `04-blue-box-perspective.png` | A blue-grey box with a recipe card ("Grandma's Apple Pie") open in the lid and category tabs fanned in perspective. | R18: the preferred later look (perspective Fan). v1 gets depth cues only; see docs/prd.md section 4. |
